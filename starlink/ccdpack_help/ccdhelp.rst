CCDHELP
#######


Purpose
~~~~~~~
Gives help about CCDPACK


Description
~~~~~~~~~~~
Displays help about CCDPACK using the CCDHELP.SHL library.
Here are some of the main options: CCDHELP No parameter is given so
the introduction and the top-level help index is displayed. CCDHELP
application Gives help on the named application.
Once in the help library, it can be navigated in the normal way.
CTRL/Z to exit from any level, and <CR> to move up a level in the
hierarchy.


Usage
~~~~~


::


       CCDHELP [TOPIC] [SUBTOPIC] [SUBSUBTOPIC] [SUBSUBSUBTOPIC]
