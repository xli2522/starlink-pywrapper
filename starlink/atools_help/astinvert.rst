ASTINVERT
#########


Purpose
~~~~~~~
Invert a Mapping


Description
~~~~~~~~~~~
This application inverts a Mapping. If a FrameSet is supplied, the
Base and Current Frames will be swapped.


Usage
~~~~~


::


       astinvert this result




ADAM parameters
~~~~~~~~~~~~~~~



FMT = LITERAL (Read)
````````````````````
The format in which to store output objects. For allowed values, see
the top level help for the ATOOLS package using command 'atlhelp'.
Only used if the output object is written to a text file. An error is
reported if the output object cannot be written using the requested
format. ["AST"]



RESULT = LITERAL (Read)
```````````````````````
An text file to receive the inverted Mapping.



THIS = LITERAL (Read)
`````````````````````
An NDF or text file holding the Mapping. If an NDF is supplied, the
Mapping from the base Frame of the WCS FrameSet to the current Frame
